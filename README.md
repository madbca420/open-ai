## 🎯 Project Vision & Goal

> **JARVIS** is a next-generation AI-powered desktop assistant built with Electron + React that goes far beyond simple chatting.
> It **autonomously thinks**, **selects the best AI model**, **divides tasks between specialist agents**, **generates full-stack code in any language**, **builds and previews websites live**, **manages missions**, and **integrates with 5+ external AI ecosystems** — all without the user manually selecting a model or provider.

```
┌─────────────────────────────────────────────────────────────────────┐
│  USER SENDS A PROMPT → JARVIS TAKES OVER COMPLETELY                 │
│                                                                     │
│  ① Classifies intent  ② Selects best model  ③ Decomposes task      │
│  ④ Routes to specialist  ⑤ Executes  ⑥ Returns polished result     │
└─────────────────────────────────────────────────────────────────────┘
```

## 🚀 Getting Started

### Prerequisites

```bash
Node.js >= 18.x
npm >= 9.x
Python 3.x (for Python backend generation)
Java JDK 17+ (for Spring Boot generation)
Go 1.21+ (for Go Gin generation)
```

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/madbca420/open-ai.git
cd open-ai

# 2. Install dependencies
npm install

# 3. Run in development (Electron desktop app)
npm start

# 4. Or run as web app only (browser mode)
npm run dev
# Open http://localhost:5173
```

### Build for Production

```bash
# Full production build
npm run build

# Build renderer only
npm run build:renderer

# Build Electron main process only
npm run build:electron

# TypeScript type check
npm run typecheck
```
