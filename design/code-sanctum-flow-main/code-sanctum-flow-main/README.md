# Jarvis Command Hub

DESIGN A COMPLETE JARVIS AI COMMAND CENTER DASHBOARD.

Use the attached reference image as the EXACT visual direction and composition reference. Recreate the same overall visual language, density, hierarchy, futuristic atmosphere, panel arrangement, central AI workspace concept, and premium cyberpunk pixel-art aesthetic, but make it an original interface for my own JARVIS AI system.

The design must feel like a LIVING AI DEVELOPMENT HEADQUARTERS, not a normal SaaS dashboard.

==================================================

CORE VISUAL CONCEPT

==================================================

Create a futuristic underground AI command room where multiple AI agents are physically working on a software mission.

The CENTER of the screen is the hero area.

Place three AI developers inside a dark futuristic development room:

1. DeepSeek V4 Flash

   Role: Primary Developer

   Color identity: Electric Blue / Cyan

2. GLM-4.5-Air

   Role: Architect

   Color identity: Orange / Gold

3. GPT-OSS 20B

   Role: Code Reviewer

   Color identity: Purple

Each model must have its own workstation with:

- Pixel-art character

- Multiple monitors

- Keyboard

- Desk

- Small desk objects

- Computer equipment

- Environmental lighting

- Individual model identity

- Status indicator

The three characters should look like actual AI workers inside the room.

==================================================

LIVING AI AGENTS

==================================================

This is the MOST IMPORTANT visual feature.

The characters must visually communicate what the AI is currently doing.

When an agent is working:

- Character is actively typing

- Hands move toward keyboard

- Head subtly moves

- Monitor content changes

- Code scrolls on monitors

- Keyboard lights pulse

- Small particles/data effects appear

- Character posture changes naturally

- Status indicator shows WORKING

When thinking:

- Character stops typing

- Looks toward another monitor

- Thinking animation

- Holographic architecture/data appears

- Subtle glowing symbols appear

When reviewing:

- Character focuses on monitor

- Code scrolls

- Highlighted lines appear

- Warning/check icons appear

When debugging:

- Error appears on monitor

- Character reacts

- Red warning indicator appears

- After resolution, the environment changes back to normal

When completed:

- Character stops typing

- Green checkmark appears

- Subtle success animation

- Status changes to COMPLETED

When idle:

- Character has a relaxed workstation animation

- Monitor remains active

- Very subtle ambient movement

The characters should NEVER look frozen or like static illustrations.

==================================================

The bubble must communicate what that AI is currently doing.
